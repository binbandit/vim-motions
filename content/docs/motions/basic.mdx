Character and line steps from `:help left-right-motions` and `:help up-down-motions`.

Highlighted cell = cursor (`|` in the source).

## Left / right

<MotionList>
  <Motion
    keys="h"
    name="Left"
    before={'vim| rocks'}
    after={'vi|m rocks'}
  />
  <Motion
    keys="l"
    name="Right"
    before={'vi|m rocks'}
    after={'vim| rocks'}
  />
  <Motion
    keys="Space"
    name="Right"
    sameAs="l"
    before={'vi|m rocks'}
    after={'vim| rocks'}
  />
  <Motion
    keys="BS"
    name="Left"
    also={['Ctrl-h']}
    before={'vim| rocks'}
    after={'vi|m rocks'}
    note="Can cross lines depending on 'whichwrap'."
  />
  <Motion keys="Ctrl-h" name="Backspace alias" sameAs="BS" sameAsLabel="Same as" />
</MotionList>

Prefer <Keys keys="h j k l" /> over arrows so hands stay on the home row.

## Up / down

<MotionList>
  <Motion
    keys="k"
    name="Up one line"
    also={['Ctrl-p']}
    before={'line one\nline |two'}
    after={'line |one\nline two'}
  />
  <Motion
    keys="j"
    name="Down one line"
    also={['Ctrl-j', 'Ctrl-n']}
    before={'line |one\nline two'}
    after={'line one\nline |two'}
  />
  <Motion
    keys="gk"
    name="Up one screen line"
    example="Respects wrap; also g↑"
  />
  <Motion
    keys="gj"
    name="Down one screen line"
    example="Also g↓ — use when 'wrap' is on"
  />
  <Motion
    keys="-"
    name="Up [count] lines to first non-blank"
    before={'  alpha\n  |bravo'}
    after={'  |alpha\n  bravo'}
  />
  <Motion
    keys="+"
    name="Down [count] lines to first non-blank"
    also={['Enter', 'Ctrl-m']}
    before={'  |alpha\n  bravo'}
    after={'  alpha\n  |bravo'}
  />
  <Motion
    keys="_"
    name="Down [count]-1 lines to first non-blank"
    before={'    |indented'}
    after={'    |indented'}
    note="Alone, _ jumps to the first non-blank of the current line."
  />
</MotionList>

## Soft wrap

When `'wrap'` is on, <Keys keys="j" link />/<Keys keys="k" link /> move by **buffer lines**. Use <Keys keys="gj" link />/<Keys keys="gk" link /> for **screen rows**.

## Habits

| Goal | Prefer |
| --- | --- |
| Next word | <Keys keys="w" link /> not many <Keys keys="l" link /> |
| End of line | <Keys keys="$" link /> |
| Matching paren | <Keys keys="%" link /> |
| Find on line | <Keys keys="f" /> / <Keys keys="t" /> |
| Screen row | <Keys keys="gj" link /> / <Keys keys="gk" link /> |
