## Soft wrap

When `'wrap'` is on, <Keys keys="j" />/<Keys keys="k" /> move by **buffer lines**. Use <Keys keys="gj" />/<Keys keys="gk" /> for **screen rows**. Pair with <Keys keys="g0" /> <Keys keys="g$" /> on [Lines](/docs/motions/lines).

## With operators

| Combo | Result |
| --- | --- |
| <Keys keys="dl" link /> | Delete character under cursor (≈ <Keys keys="x" link />) |
| <Keys keys="dh" link /> | Delete character to the left (≈ <Keys keys="X" link />) |
| <Keys keys="dj" /> | Delete this line and the next |
| <Keys keys="d+" /> | Delete through next line (to first non-blank target) |

## Habits

| Goal | Prefer |
| --- | --- |
| Next word | <Keys keys="w" /> not many <Keys keys="l" /> |
| End of line | <Keys keys="$" /> |
| Matching paren | <Keys keys="%" /> |
| Find on line | <Keys keys="f" /> / <Keys keys="t" /> |
| Screen row | <Keys keys="gj" /> / <Keys keys="gk" /> |
