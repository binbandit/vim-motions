Far motions push the previous position onto the **jump list**. Near motions
(like <Keys keys="h" link /> / <Keys keys="w" link />) usually do not.

## Jump list

Start at `count`, jump with `G` to the last line, then come back:

<Motion
  keys="Ctrl-o"
  name="Older jump"
  before={"count = 1\nextra = 2\nprint(|count|)"}
  after={"|count = 1\nextra = 2\nprint(count)"}
  note="After G (or /search, gd, …), Ctrl-o walks back through jump history."
/>

<Motion
  keys="Ctrl-i"
  name="Newer jump"
  before={"|count = 1\nextra = 2\nprint(count)"}
  after={"count = 1\nextra = 2\nprint(|count|)"}
  note="Forward again — Tab often sends Ctrl-i in the terminal."
/>

<Motion
  keys="''"
  name="Line before the latest jump"
  before={"count = 1\nextra = 2\nprint(|count|)"}
  after={"|count = 1\nextra = 2\nprint(count)"}
  note="After a jump that left line 1, '' returns to that line (first non-blank)."
/>

<Motion
  keys="``"
  name="Exact position before the latest jump"
  before={"count = 1\nextra = 2\nprint(|count|)"}
  after={"co|unt = 1\nextra = 2\nprint(count)"}
  note="After jumping away from column 3 of line 1, `` restores that exact position (not just the line)."
/>

<MotionList>
  <Motion keys=":jumps" name="Show jump list" />
  <Motion keys=":clearjumps" name="Clear jump list" />
</MotionList>

Use <Keys keys="g'{mark}" /> / <Keys keys="g`{mark}" /> to jump to a mark **without**
adding a jumplist entry.

## Change list

Positions of edits, separate from jumps. After editing `old` then moving away:

<Motion
  keys="g;"
  name="Older change position"
  before={"renamed = 1\nprint(|other|)"}
  after={"|renamed = 1\nprint(other)"}
  note="Jumps to where you last changed text (here: the rename on line 1)."
/>

<Motion
  keys="g,"
  name="Newer change position"
  before={"|renamed = 1\nprint(other)"}
  after={"renamed = 1\nprint(|other|)"}
/>

<MotionList>
  <Motion keys=":changes" name="Show change list" />
  <Motion keys="'." name="Last change line" />
  <Motion keys="`." name="Last change exact position" />
</MotionList>

## Motions that typically jump

Examples that usually add jumplist entries (not exhaustive):

- <Keys keys="'" /> / <Keys keys="`" /> marks
- <Keys keys="G" /> <Keys keys="gg" /> <Keys keys="{count}%" /> <Keys keys="/" /> <Keys keys="?" /> <Keys keys="n" /> <Keys keys="N" />
- <Keys keys="(" /> <Keys keys=")" /> <Keys keys="{" /> <Keys keys="}" />
- <Keys keys="[[" /> <Keys keys="]]" /> <Keys keys="H" /> <Keys keys="L" /> <Keys keys="M" /> (often)
- <Keys keys="%" /> when it moves far
- <Keys keys="*" /> <Keys keys="#" /> <Keys keys="gd" /> <Keys keys="gD" />

Exact rules: `:help jump-motions`.
