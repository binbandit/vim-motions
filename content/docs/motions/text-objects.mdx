Text objects answer: *what thing am I editing?* Use them **after** an operator, or in Visual mode (`:help object-select`).

Highlighted cell = cursor. `|region|` shows the span the object targets. Examples
show the **edit** result (usually with `d` / `c`).

## Inner vs a (around)

| Prefix | Meaning |
| --- | --- |
| <Keys keys="i" link /> | **Inner** — contents only |
| <Keys keys="a" link /> | **A / around** — contents + delimiters / whitespace |

## Words

<MotionList>
  <Motion
    keys="iw"
    name="Inner word"
    before={'edit the |user_name| now'}
    after={'edit the |user_name| now'}
    note="Selects the whole iskeyword word — user_name is one word; userNameToday would be too (no camelCase split)."
  />
  <Motion
    keys="aw"
    name="A word (with surrounding space)"
    before={'keep |drop| keep'}
    after={'keep |drop| keep'}
  />
  <Motion keys="iW" name="Inner WORD" />
  <Motion keys="aW" name="A WORD" />
</MotionList>

<Buffer
  keys="diw"
  before={'edit the |user_name| now'}
  after={'edit the | now'}
  note="Cursor anywhere in user_name — iw targets the whole word."
/>

<Buffer
  keys="daw"
  before={'keep |drop| keep'}
  after={'keep |keep'}
  note="aw also eats a neighboring space."
/>

## Quotes

Quote objects are **single-line only**. If the cursor sits on a quote character,
Vim picks the pair counting from the start of the line. `a"` may include a
**leading** space when there is no trailing space after the closing quote.

<MotionList>
  <Motion keys={'i"'} name={'Inner double quotes i"'} />
  <Motion keys={'a"'} name={'A double-quoted string a"'} />
  <Motion keys="i'" name="Inner single quotes i'" />
  <Motion keys="a'" name="A single-quoted string a'" />
  <Motion keys="i`" name="Inner backticks i`" />
  <Motion keys="a`" name="A backtick string a`" />
</MotionList>

<Buffer
  keys='ci"'
  before={'msg = "|hello|"'}
  after={'msg = "|"'}
  note="Classic: change inside quotes, type replacement, Esc."
/>

<Buffer
  keys='da"'
  before={'msg = "|hello|"'}
  after={'msg |='}
  note="Around — removes the quotes; cursor lands on `=`."
/>

## Everyday combos

| Combo | Result |
| --- | --- |
| <Keys keys={'ci"'} /> | Replace string contents |
| <Keys keys="ci(" link /> | Replace inside call/args |
| <Keys keys="ca{" /> | Replace block including braces |
| <Keys keys="cit" link /> | Change inside HTML tag |
| <Keys keys="yap" link /> | Copy paragraph |
| <Keys keys="cgn" /> | Change next search match |
