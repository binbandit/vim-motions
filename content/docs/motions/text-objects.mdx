Text objects answer: *what thing am I editing?* Use them **after** an operator, or in Visual mode (`:help object-select`).

Highlighted cell = cursor. Examples show the **edit** result (usually with `d` / `c`).

## Inner vs a (around)

| Prefix | Meaning |
| --- | --- |
| <Keys keys="i" link /> | **Inner** — contents only |
| <Keys keys="a" link /> | **A / around** — contents + delimiters / whitespace |

## Everyday combos

| Combo | Result |
| --- | --- |
| <Keys keys={'ci"'} /> | Replace string contents |
| <Keys keys="ci(" link /> | Replace inside call/args |
| <Keys keys="ca{" /> | Replace block including braces |
| <Keys keys="cit" link /> | Change inside HTML tag |
| <Keys keys="yap" link /> | Copy paragraph |
| <Keys keys="cgn" /> | Change next search match |
