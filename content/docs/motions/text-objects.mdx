Text objects answer: *what thing am I editing?* Use them **after** an operator, or in Visual mode. They are listed in `:help object-select`.

```text
d i w     delete inner word
c a "     change a quoted string (includes quotes)
v i [     visually select inside brackets
y a p     yank a paragraph
d g n     delete next search match (see Search)
```

## Inner vs a (around)

| Prefix | Meaning |
| --- | --- |
| <Keys keys="i" /> | **Inner** — contents only |
| <Keys keys="a" /> | **A / around** — contents + delimiters / whitespace |

## Search match as object

<Keys keys="gn" /> / <Keys keys="gN" /> select the next/previous search match and work with operators (`dgn`, `cgn`). Full detail: [Search](/docs/motions/search).

## Everyday combos

| Combo | Result |
| --- | --- |
| <Keys keys={'ci"'} /> | Replace string contents |
| <Keys keys="ci(" /> | Replace inside call/args |
| <Keys keys="ca{" /> | Replace block including braces |
| <Keys keys="cit" /> | Change inside HTML tag |
| <Keys keys="dit" /> | Delete tag contents |
| <Keys keys="yap" /> | Copy paragraph |
| <Keys keys="=ip" /> | Re-indent paragraph |
| <Keys keys=">ap" /> | Indent paragraph |
| <Keys keys="gUiw" /> | Uppercase word |
| <Keys keys="cgn" /> | Change next search match |

## Nesting

With nested brackets, Vim picks the **smallest** object containing the cursor. Move inside the pair you want first, or use Visual and expand.

## Plugins (not built-in)

Argument objects (`ia`/`aa`), function bodies, etc. come from plugins (targets.vim, mini.ai, nvim-treesitter-textobjects). This site documents **built-in** objects only.
