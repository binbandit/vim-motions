---
title: Marks as Motions
description: Every mark jump that moves the cursor — including automatic marks.
---

Setting a mark (`m{a-z}`) is not a motion. **Jumping** to a mark is.

For workflows and `:marks`, see also [Navigation → Marks](/docs/navigation/marks).

## User marks

Set mark `a` on `userName`, move away, then jump back:

<Motion
  keys="'a"
  name="Jump to mark line (first non-blank)"
  before={"const userName = 1\nprint(|x|)"}
  after={"|const userName = 1\nprint(x)"}
  note="After ma on the first line, 'a returns to that line."
/>

<Motion
  keys="`a"
  name="Jump to exact mark position"
  before={"const userName = 1\nprint(|x|)"}
  after={"const |userName = 1\nprint(x)"}
  note="Restores column too — cursor lands on the marked character."
/>

</MotionList>

## Jump history marks

After `G` from the top:

<Motion
  keys="''"
  name="Line of position before latest jump"
  before={"one\ntwo\n|three"}
  after={"|one\ntwo\nthree"}
/>

<Motion
  keys="``"
  name="Exact position before latest jump"
  before={"one\ntwo\n|three"}
  after={"o|ne\ntwo\nthree"}
  note="If you left from column 1 of `one`, `` restores that column."
/>

## Change / Insert / Visual / yank marks

After `ciw` replaced `old` with `newName`:

<Motion
  keys="`["
  name="Start of last change or yank"
  before={"const newName| = 1"}
  after={"const |newName = 1"}
/>

<Motion
  keys="`]"
  name="End of last change or yank"
  before={"const |newName = 1"}
  after={"const newNam|e = 1"}
/>

<Motion
  keys="`."
  name="Exact last change"
  before={"const newName = 1\nprint(|x|)"}
  after={"const newNam|e = 1\nprint(x)"}
/>

## Walk lowercase marks

With marks `a` on line 1 and `b` on line 3:

<Motion
  keys="]'"
  name="Next lowercase mark (line)"

  after={"const a = 1\nmiddle\n|const b = 2"}

## Ex helpers

| Command | Meaning |
| --- | --- |
| `:marks` | List marks |
| `:delmarks a b p-z` | Delete marks |
| `:delmarks!` | Delete all lowercase marks |
| `:lockmarks {cmd}` | Run `{cmd}` without moving marks |
| `:keepjumps {cmd}` | Run `{cmd}` without adding jumplist entries |
