## Line operators (shorthand)

| Keys | Meaning |
| --- | --- |
| <Keys keys="dd" /> | Delete line |
| <Keys keys="cc" /> / <Keys keys="S" /> | Change line |
| <Keys keys="yy" /> / <Keys keys="Y" /> | Yank line (`Y` is linewise like `yy` in Vim) |
| <Keys keys="D" /> | Delete to end of line (`d$`) |
| <Keys keys="C" /> | Change to end of line (`c$`) |
| <Keys keys="I" /> | Insert at first non-blank |
| <Keys keys="A" /> | Append at end of line |

## Soft wrap note

When `wrap` is on, <Keys keys="j" />/<Keys keys="k" /> move by **buffer lines**. Use <Keys keys="gj" />/<Keys keys="gk" /> to move by **screen rows**.
