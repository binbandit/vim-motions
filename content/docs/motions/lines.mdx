## Across the file

<MotionList>
  <Motion keys="gg" name="Line [count] (default 1)" also={["Ctrl-Home"]} example="Linewise · adds to jumplist" />
  <Motion keys="G" name="Line [count] (default last)" example="Linewise · jumplist" />
  <Motion keys="Ctrl-End" name="Go to last character of last line" sameAs="G" sameAsThen="$" />
  <Motion keys="{count}%" name="To count% through the file" example="Linewise · formula: (count * lines + 99) / 100" />
  <Motion keys=":{n}" name="Ex goto line n" example=":80 then Enter" />
  <Motion keys="go" name="Goto byte [count] in the buffer" example="Also :go[to] · default 1 · respects 'fileformat' EOL size" />
</MotionList>

**Reminder:** <Keys keys="%" /> without a count is **match item** ([Matching](/docs/motions/matching)), not percentage. Percentage always needs a count: <Keys keys="50%" />.

## Line operators (shorthand)

| Keys | Meaning |
| --- | --- |
| <Keys keys="dd" /> | Delete line |
| <Keys keys="cc" /> / <Keys keys="S" /> | Change line |
| <Keys keys="yy" /> / <Keys keys="Y" /> | Yank line |
| <Keys keys="D" link /> | Delete to end of line (<SameAs keys="d$" />) |
| <Keys keys="C" link /> | Change to end of line (<SameAs keys="c$" />) |
| <Keys keys="I" /> | Insert at first non-blank |
| <Keys keys="A" /> | Append at end of line |

## Soft wrap

<Keys keys="j" />/<Keys keys="k" /> = buffer lines. <Keys keys="gj" />/<Keys keys="gk" /> = screen rows. See [Basic](/docs/motions/basic).
