Canonical list aligned with Vim 9 [`:help motion.txt`](https://vimhelp.org/motion.txt.html) plus search commands from [`:help pattern.txt`](https://vimhelp.org/pattern.txt.html) and fold motions from [`:help fold.txt`](https://vimhelp.org/fold.txt.html).

Each row below is a real motion entry (searchable). Symbol keys include plain-language names so `*` / `#` / `%` are easy to find.

## Not motions (nearby)

View-only scroll: <Keys keys="Ctrl-e" />, <Keys keys="Ctrl-y" />, <Keys keys="zh" />, <Keys keys="zl" />.  
Cursor+view page moves: <Keys keys="Ctrl-d" link />, <Keys keys="Ctrl-u" link />, <Keys keys="Ctrl-f" link />, <Keys keys="Ctrl-b" link /> — [Scrolling](/docs/motions/scrolling).  
Redraw: <Keys keys="zz" link />, <Keys keys="zt" link />, <Keys keys="zb" link />.  
Setting marks (`m{a-z}`) is not a motion; jumping to them is.
