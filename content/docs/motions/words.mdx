Vim has two notions of “word”:

- **word** (`w`/`e`/`b`) — letters, digits, underscores as one class; punctuation is separate
- **WORD** (`W`/`E`/`B`) — any non-blank sequence separated only by whitespace

## Operator tips

| Combo | Why |
| --- | --- |
| <Keys keys="dw" /> | Deletes from cursor to next word start (often includes trailing space) |
| <Keys keys="de" /> | Deletes through end of word (keeps following space) |
| <Keys keys="diw" /> | Deletes the whole word under cursor (text object — usually what you want) |
| <Keys keys="daw" /> | Deletes word **and** surrounding whitespace |
| <Keys keys="cw" /> | Change to next word (classic; often similar to `ce`) |

## Code example

```text
const userName = fetchUser();
     ^
```

- Cursor on `u` of `userName`
- <Keys keys="w" /> → `=`
- <Keys keys="W" /> → `fetchUser();` start (depends on spacing)
- <Keys keys="diw" /> → deletes `userName`
- <Keys keys="daw" /> → deletes `userName` and a neighboring space
