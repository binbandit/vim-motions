Vim has two notions of “word” (`:help word-motions`):

- **word** (`w`/`e`/`b`/`ge`) — letters, digits, underscores as one class; punctuation is separate
- **WORD** (`W`/`E`/`B`/`gE`) — non-blank sequences separated only by whitespace

## Operator tips

| Combo | Why |
| --- | --- |
| <Keys keys="dw" /> | Deletes to next word start (often includes trailing space) |
| <Keys keys="de" /> | Deletes through end of word (keeps following space) |
| <Keys keys="diw" /> | Deletes the whole word under cursor (text object) |
| <Keys keys="daw" /> | Deletes word **and** surrounding whitespace |
| <Keys keys="cw" /> | Change to next word (often similar to `ce`) |
| <Keys keys="dge" /> | Delete back through end of previous word |

## Code example

```text
const userName = fetchUser();
     ^
```

- Cursor on `u` of `userName`
- <Keys keys="w" /> → start of next word after `userName`
- <Keys keys="e" /> → last char of `userName`
- <Keys keys="diw" /> → deletes `userName`
- <Keys keys="daw" /> → deletes `userName` and a neighboring space

## Special empty-line behavior

On an empty line, `w`/`W` move to the first word of the next non-empty line; `b`/`B` similarly go backward. See `:help word-motions` for edge cases with operators at EOL.
