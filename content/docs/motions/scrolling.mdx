## Window-relative motions

These **are** motions (usable with operators: `yH`, `dL`, …). Imagine a window
showing five lines — cursor starts in the middle:

```
1  alpha     ← H (top)
2  bravo
3  |charlie  ← M (middle) — you are here
4  delta
5  echo      ← L (bottom)
```

<Motion
  keys="H"
  name="To first visible line (Home)"
  before={"alpha\nbravo\n|charlie\ndelta\necho"}
  after={"|alpha\nbravo\ncharlie\ndelta\necho"}
  note="In a real window this is the top *visible* line, not necessarily line 1 of the file."
/>

<Motion
  keys="M"
  name="Middle line of window"
  before={"|alpha\nbravo\ncharlie\ndelta\necho"}
  after={"alpha\nbravo\n|charlie\ndelta\necho"}
/>

<Motion
  keys="L"
  name="To last visible line (Low)"
  before={"alpha\nbravo\n|charlie\ndelta\necho"}
  after={"alpha\nbravo\ncharlie\ndelta\n|echo"}
/>

Cursor lands on the first non-blank (see `'startofline'`). Adjusted for
`'scrolloff'` unless an operator is pending.

### With an operator

<Buffer
  keys="dL"
  before={"keep\n|drop\nalso drop\nlast visible\nbelow window"}
  after={"keep\n|below window"}
  note="Deletes from the current line through the last visible line."
/>

## Page & half-page (move cursor + view)

From `:help scroll.txt` — these move the cursor as they scroll. Exact line
counts depend on window height; demos show the *idea*:

<Motion
  keys="Ctrl-d"
  name="Half-page down"
  before={"|line 1\nline 2\nline 3\nline 4\nline 5\nline 6"}
  after={"line 1\nline 2\nline 3\n|line 4\nline 5\nline 6"}
  note="Also scrolls the view — cursor moves down by roughly half a screen."
/>

<Motion
  keys="Ctrl-u"
  name="Half-page up"
  before={"line 1\nline 2\nline 3\n|line 4\nline 5\nline 6"}
  after={"|line 1\nline 2\nline 3\nline 4\nline 5\nline 6"}
/>

## View-only scroll (not operator motions)

Cursor tries to stay put — the **viewport** moves, so before/after buffers look
identical. Use these to peek without losing your place:

<MotionList>
  <Motion keys="Ctrl-e" name="Scroll down one line" example="View moves down; cursor text stays the same if possible" />
  <Motion keys="Ctrl-y" name="Scroll up one line" />
  <Motion keys="zh" name="Scroll left one character" />
  <Motion keys="zl" name="Scroll right one character" />
  <Motion keys="zH" name="Scroll half screen left" />
  <Motion keys="zL" name="Scroll half screen right" />
  <Motion keys="zs" name="Scroll: cursor to leftmost screen column" />

</MotionList>

## Redraw cursor line

These also keep the same buffer text — they reposition which screen row your
line sits on:

<MotionList>
  <Motion keys="zz" name="Center cursor line" example="Cursor stays on the same text; line moves to middle of window" />
  <Motion keys="zt" name="Cursor line to top of window" />
  <Motion keys="zb" name="Cursor line to bottom of window" />
  <Motion keys="z." name="Center, then first non-blank" example="Like zz, then move to first non-blank (^)" />
  <Motion keys="z-" name="Bottom, then first non-blank" example="Like zb, then first non-blank" />
  <Motion keys="zEnter" name="Top, then first non-blank" example="z&lt;CR&gt; — like zt, then first non-blank" />
</MotionList>

## Tip

With `'relativenumber'`, type <Keys keys="12j" /> instead of searching. Pair big
jumps with <Keys keys="zz" /> to stay oriented.
