Section motions jump by **sections** (form-feed / nroff section macros) or, in
practice for code, by `{` / `}` in **column 1**.

These examples use top-level braces in column 1 (typical C / Go style):

```
fn a() {
  …
}

fn b() {
  …
}
```

<Motion
  keys="]]"
  name="Next section / next { in column 1"
  before={"fn a() |{\n  return 1\n}\n\nfn b() {\n  return 2\n}"}
  after={"fn a() {\n  return 1\n}\n\nfn b() |{\n  return 2\n}"}
  note="From inside / on a column-1 `{`, jump to the next column-1 `{`."
/>

<Motion
  keys="]["
  name="Next } in column 1"
  before={"fn a() |{\n  return 1\n}\n\nfn b() {\n  return 2\n}"}
  after={"fn a() {\n  return 1\n|}\n\nfn b() {\n  return 2\n}"}
/>

<Motion
  keys="[["
  name="Previous { in column 1"
  before={"fn a() {\n  return 1\n}\n\nfn b() |{\n  return 2\n}"}
  after={"fn a() |{\n  return 1\n}\n\nfn b() {\n  return 2\n}"}
/>

<Motion
  keys="[]"
  name="Previous } in column 1"
  before={"fn a() {\n  return 1\n}\n\nfn b() |{\n  return 2\n}"}
  after={"fn a() {\n  return 1\n|}\n\nfn b() {\n  return 2\n}"}
/>

These are exclusive; with operators they often become **exclusive-linewise**.

## What is a section?

A section begins after a form-feed (`Ctrl-l`) in column 1, and at macros listed
in the `'sections'` option (default nroff-style `.SH`, `.NH`, …).

In C-like code without those macros, think “next/previous top-level `{`/`}`”.
