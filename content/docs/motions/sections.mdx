Section motions jump by **sections** (form-feed / nroff macros) or, in code, by
`{` / `}` that sit in **column 1**.

Braces mid-line (`fn a() {`) do **not** count — only a `{` or `}` as the first
character of the line.

```
{          ← column 1
  body
}

{
  next
}
```

<Motion
  keys="]]"
  name="Next section start / next { in column 1"
  before={"|{\n  a()\n}\n\n{\n  b()\n}"}
  after={"{\n  a()\n}\n\n|{\n  b()\n}"}
  note="From a column-1 `{`, jump to the next column-1 `{`."
/>

<Motion
  keys="]["
  name="Next } in column 1"
  before={"|{\n  a()\n}\n\n{\n  b()\n}"}
  after={"{\n  a()\n|}\n\n{\n  b()\n}"}
/>

<Motion
  keys="[["
  name="Previous { in column 1"
  before={"{\n  a()\n}\n\n|{\n  b()\n}"}
  after={"|{\n  a()\n}\n\n{\n  b()\n}"}
/>

<Motion
  keys="[]"

  before={"{\n  a()\n}\n\n|{\n  b()\n}"}

/>

These are exclusive; with operators they often become **exclusive-linewise**.

## What is a section?

A section begins after a form-feed (`Ctrl-l`) in column 1, and at macros listed
in the `'sections'` option (default nroff-style `.SH`, `.NH`, …).

In C-like code without those macros, put opening braces on their own line (or
accept that mid-line `{` won’t be found).
