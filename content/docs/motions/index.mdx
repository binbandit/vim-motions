This section mirrors Vim’s own [`:help motion.txt`](https://vimhelp.org/motion.txt.html) so you can find anything that ships with Vim.

## Inclusive vs exclusive

Some motions include the end character (**inclusive**); others stop before it (**exclusive**). Linewise motions operate on whole lines. You rarely memorize the formal rule — notice what <Keys keys="d" /> deletes and adjust (`t` vs `f`, `e` vs `w`).

## Forced motion type

After an operator, you can force the pending motion’s type:

| Keys | Force |
| --- | --- |
| <Keys keys="v" /> | Characterwise |
| <Keys keys="V" /> | Linewise |
| <Keys keys="Ctrl-v" /> | Blockwise |

Example: <Keys keys="dV}" /> deletes linewise to the next paragraph (see `:help o_v`).
