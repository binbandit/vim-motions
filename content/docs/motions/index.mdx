A **motion** moves the cursor. With an operator waiting, the same motion selects the range to act on.

Each family page includes **before/after buffer demos** — `|` marks the cursor
(and `|region|` highlights a span).

This section mirrors Vim’s [`:help motion.txt`](https://vimhelp.org/motion.txt.html) and search commands from [`:help pattern.txt`](https://vimhelp.org/pattern.txt.html).

## Inclusive vs exclusive

Some motions include the end character (**inclusive**); others stop before it (**exclusive**). Linewise motions operate on whole lines. Notice what <Keys keys="d" link /> deletes and adjust (`t` vs `f`, `e` vs `w`).

## Forced motion type

After an operator, force the pending motion’s type:

| Keys | Force |
| --- | --- |
| <Keys keys="v" link /> | Characterwise |
| <Keys keys="V" link /> | Linewise |
| <Keys keys="Ctrl-v" link /> | Blockwise |

Example: <Keys keys="dV}" /> deletes linewise to the next paragraph (see `:help o_v`).
