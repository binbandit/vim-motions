## Search options worth knowing

In command mode:

- `\c` — case-insensitive for this search
- `\C` — case-sensitive
- `\<` `\>` — word boundaries
- Very magic: `\v` so you can write `(foo|bar)` more naturally

## Search as a motion

Operators accept search motions:

```text
d/foo<CR>   delete until next "foo"
c?bar<CR>   change backward until "bar"
y*          yank through next occurrence of current word
```

## Clear highlight

`:noh` or `:nohlsearch` clears search highlighting until the next search.
