Find text on a line or in the file. These are full motions — operators accept them (`d/foo`, `cgn`, `y*`).

In examples, the highlighted block is the **cursor** position (`|` in the source).

## Word under cursor (`*` / `#`)

<MotionList>
  <Motion
    keys="*"
    name="Star (*) — search word under cursor forward"
    before={'total = count + 1\nextra = |count| * 2\nprint(count)'}
    after={'total = count + 1\nextra = count * 2\nprint(|count|)'}
    note="Jumps to the next whole-word match of count (like /\<count\>)."
  />
  <Motion
    keys="#"
    name="Hash (#) — search word under cursor backward"
    before={'total = count + 1\nextra = |count| * 2\nprint(count)'}
    after={'total = |count| + 1\nextra = count * 2\nprint(count)'}
    note="Same as * but searches upward. Also called pound."
  />
  <Motion
    keys="g*"
    name="g-star (g*) — search forward, not whole-word"
    before={'id = user_id\nprint(|user|)'}
    after={'id = |user|_id\nprint(user)'}
    note="Matches user inside user_id because there are no \< \> boundaries. Related to *, not the same."
  />
  <Motion
    keys="g#"
    name="g-hash (g#) — search backward, not whole-word"
    before={'id = user_id\nprint(|user|)'}
    after={'id = |user|_id\nprint(user)'}
    note="Backward sibling of g* — related to #, not identical."
  />
</MotionList>

## Find on the current line

<MotionList>
  <Motion
    keys="f{char}"
    name="Find char forward"
    before={'price = |42.50;'}
    after={'price = 42.50|;'}
    note="f; lands on the semicolon (inclusive)."
  />
  <Motion
    keys="F{char}"
    name="Find char backward"
    before={'price = 42.50|;'}
    after={'price |= 42.50;'}
    note="F= jumps back onto the equals."
  />
  <Motion
    keys="t{char}"
    name="Till before char forward"
    before={'href=|"/docs"'}
    after={'href="/doc|s"'}
    note="From the opening quote, t&quot; stops on the character before the closing quote (s). Great for dt&quot; / ct&quot; when you start earlier on the line."
  />
  <Motion
    keys="T{char}"
    name="Till after char backward"
    before={'href="/docs|"'}
    after={'href="|/docs"'}
    note="From the closing quote, T&quot; lands just after the opening quote."
  />
  <Motion
    keys=";"
    name="Repeat last f/F/t/T"
    before={'a,|b,c,d'}
    after={'a,b,|c,d'}
    note="After f,, pressing ; finds the next comma."
  />
  <Motion
    keys=","
    name="Repeat last f/F/t/T opposite direction"
    before={'a,b,|c,d'}
    after={'a,|b,c,d'}
  />
</MotionList>

| Goal | Keys |
| --- | --- |
| Delete until `)` exclusive | <Keys keys="dt)" /> |
| Delete through `)` | <Keys keys="df)" /> |
| Change until `=` | <Keys keys="ct=" /> |

<Buffer
  keys="dt)"
  before={'print(|name)'}
  after={'print(|)'}
  note="t stops before ); d deletes up to but not including it."
/>

## Search in the file

<MotionList>
  <Motion
    keys="/"
    name="Search forward"
    id="slash"
    before={'TODO: wire auth\nfix login\n|TODO: tests'}
    after={'|TODO: wire auth\nfix login\nTODO: tests'}
    note="Type /TODO then Enter. Cursor moves to the match (exclusive motion)."
  />
  <Motion
    keys="?"
    name="Search backward"
    id="qmark"
    before={'TODO: wire auth\nfix login\n|TODO: tests'}
    after={'|TODO: wire auth\nfix login\nTODO: tests'}
    note="?TODO&lt;CR&gt; searches upward (wraps with 'wrapscan'). From the start of line 3 it finds line 1."
  />
  <Motion
    keys="n"
    name="Next match (same direction as last search)"
    before={'|TODO: wire auth\nfix login\nTODO: tests'}
    after={'TODO: wire auth\nfix login\n|TODO: tests'}
  />
  <Motion
    keys="N"
    name="Previous match (opposite direction)"
    before={'TODO: wire auth\nfix login\n|TODO: tests'}
    after={'|TODO: wire auth\nfix login\nTODO: tests'}
  />
  <Motion
    keys="gd"
    name="Go to local declaration"
    before={'function main() {\n  const |count| = 0\n  return count\n}'}
    after={'function main() {\n  const |count| = 0\n  return count\n}'}
    note="From a use of count, gd jumps to the local declaration (same here if already on it)."
  />
  <Motion keys="gD" name="Go to global declaration" />
  <Motion keys="1gd" name="Like gd, ignore matches before cursor" example="Variant of gd — skips earlier matches on the line/file" />
  <Motion keys="1gD" name="Like gD, ignore matches before cursor" example="Variant of gD" />
</MotionList>

Offsets after a search still count as part of the motion, e.g. `/foo/e` (end of match), `/bar/+1` (line below). See `:help search-offset`.

## Operate on the match (`gn` / `gN`)

<MotionList>
  <Motion
    keys="gn"
    name="Select next search match"
    before={'rename |foo| here and foo there'}
    after={'rename |foo| here and foo there'}
    note="After searching foo (or *), gn selects that match so cgn / dgn can edit it."
  />
  <Motion keys="gN" name="Select previous search match" />
</MotionList>

<Buffer
  keys="cgn"
  before={'rename |oldName| here and oldName there'}
  after={'rename newNam|e here and oldName there'}
  note="On a search match: cgn → type newName → Esc. Then n . repeats on the next match."
/>

## Search as a motion

<Buffer
  keys="d/foo"
  before={'keep |this foo drop'}
  after={'keep |foo drop'}
  note="d/foo&lt;CR&gt; deletes from the cursor up to (not including) the match."
/>

```text
y*          yank through next occurrence of current word
cgn         change next match of last search
```

## Search options worth knowing

- `\c` / `\C` — force case-insensitive / sensitive for this search
- `\<` `\>` — word boundaries
- `\v` — very magic regex
- `:noh` / `:nohlsearch` — clear highlight until next search
