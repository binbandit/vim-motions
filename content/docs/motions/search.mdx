Find text on a line or in the file. These are full motions — operators accept them (`d/foo`, `cgn`, `y*`).

## Word under cursor (`*` / `#`)

These are among the most-used search motions:

  <Motion keys="*" name="Star (*) — search word under cursor forward" example="Whole-word \<word\> · like /\<word\>/ then n" />
  <Motion keys="#" name="Hash (#) — search word under cursor backward" example="Same as * but reverse direction · also called pound" />
  <Motion keys="g*" name="g-star (g*) — search forward, not whole-word" sameAs="*" example="No \< \> word boundaries" />
  <Motion keys="g#" name="g-hash (g#) — search backward, not whole-word" sameAs="#" />
</MotionList>

## Find on the current line

<MotionList>
  <Motion keys="f{char}" name="Find char forward" example="Inclusive · digraphs / :lmap apply to {char}" />
  <Motion keys="F{char}" name="Find char backward" />
  <Motion keys="t{char}" name="Till before char forward" example="Stops one before target — great with d/c" />
  <Motion keys="T{char}" name="Till after char backward" />
  <Motion keys=";" name="Repeat last f/F/t/T" />
  <Motion keys="," name="Repeat last f/F/t/T opposite direction" />
</MotionList>

| Goal | Keys |
| --- | --- |
| Delete until `)` exclusive | <Keys keys="dt)" /> |
| Delete through `)` | <Keys keys="df)" /> |
| Change until `=` | <Keys keys="ct=" /> |
| Jump to 2nd `_` | <Keys keys="2f_" /> |

## Search in the file

<MotionList>
  <Motion keys="/" name="Search forward" example="/TODO then Enter · exclusive motion to match" id="slash" />
  <Motion keys="?" name="Search backward" id="qmark" />
  <Motion keys="n" name="Next match (same direction as last search)" />
  <Motion keys="N" name="Previous match (opposite direction)" />
  <Motion keys="gd" name="Go to local declaration" />
  <Motion keys="gD" name="Go to global declaration" />
  <Motion keys="1gd" name="Like gd, ignore matches before cursor" sameAs="gd" />
  <Motion keys="1gD" name="Like gD, ignore matches before cursor" sameAs="gD" />
</MotionList>

Offsets after a search still count as part of the motion, e.g. `/foo/e` (end of match), `/bar/+1` (line below). See `:help search-offset`.

## Operate on the match (`gn` / `gN`)

<MotionList>
  <Motion keys="gn" name="Select next search match" example="dgn deletes the next match; cgn changes it — then . repeats" />
  <Motion keys="gN" name="Select previous search match" />
</MotionList>

Classic refactor loop:

1. <Keys keys="*" link /> or `/\<oldName\>`
2. <Keys keys="cgn" /> type `newName`, <Keys keys="Esc" link />
3. <Keys keys="n" link /> then <Keys keys="." /> (or keep using `cgn` / `.`)

<Keys keys="gn" link /> always searches **forward** for the pattern (unlike <Keys keys="n" link />, direction does not flip with <Keys keys="?" link />).

## Search as a motion

```text
d/foo<CR>   delete until next "foo"
c?bar<CR>   change backward until "bar"
y*          yank through next occurrence of current word
cgn         change next match of last search
```

## Search options worth knowing

- `\c` / `\C` — force case-insensitive / sensitive for this search
- `\<` `\>` — word boundaries
- `\v` — very magic regex
- `:noh` / `:nohlsearch` — clear highlight until next search
