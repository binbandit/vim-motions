Vim rewards a small set of ideas more than memorizing hundreds of keys.

## Core ideas

1. **Stay in Normal mode** — movement and editing live here.
2. **Compose** — operators + motions + counts.
3. **Prefer meaning over pixels** — words, sentences, paragraphs, pairs, tags.
4. **Repeat** — <Keys keys="." /> repeats the last change; macros repeat longer workflows.

## Suggested learning path

1. [Modes](/docs/getting-started/modes) — where you are
2. [Operators & motions](/docs/getting-started/operators-and-motions) — the grammar (with buffers)
3. [Counts](/docs/getting-started/counts) — multiply anything
4. [Basic](/docs/motions/basic) and [word](/docs/motions/words) motions
5. [Operators](/docs/operators) in depth (`d`, `c`, `y`)
6. [Text objects](/docs/motions/text-objects)
7. [Search](/docs/motions/search) (`f`, `t`, `/`, `gn`)
8. [Sentences & paragraphs](/docs/motions/sentences) · [Matching](/docs/motions/matching)
9. Skim [All motions](/docs/motions/all) whenever you wonder “does x exist?”

## How examples work

On motion and operator pages, **before / after** buffers show the cursor as a
highlighted cell. In the source, `|` marks the cursor; `|region|` highlights a
span the motion or object covers.

## Practice habit

Pick one motion family per day. Use it on real code until it's muscle memory, then add the next.
