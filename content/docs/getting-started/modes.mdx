Vim is modal. The same keys do different things depending on mode. Most of this reference assumes **Normal mode**.

## Mode overview

<MotionList>
  <Motion keys="Esc" name="Normal mode">
    Default mode. Move, delete, yank, jump, run counts and operators. Press Esc (or Ctrl-[) to return here.
  </Motion>
  <Motion keys="i a o O" name="Insert mode">
    Type text. Prefer short insert bursts, then Esc back to Normal.
  </Motion>
  <Motion keys="v V Ctrl-v" name="Visual mode">
    Select character-wise, line-wise, or block-wise, then operate on the selection.
  </Motion>
  <Motion keys="R" name="Replace mode">
    Overwrite characters as you type. Useful for fixed-width edits.
  </Motion>
  <Motion keys=":" name="Command-line mode">
    Ex commands: write, quit, substitute, global, set options.
  </Motion>
</MotionList>

## Leaving modes

- <Keys keys="Esc" /> or <Keys keys="Ctrl-[" /> → Normal
- In Command-line: <Keys keys="Esc" /> cancels; <Keys keys="Enter" /> runs
- In Insert: <Keys keys="Ctrl-o" /> runs one Normal command, then returns to Insert
