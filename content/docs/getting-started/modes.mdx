Vim is modal. The same keys do different things depending on mode. Most of this reference assumes **Normal mode**.

## Mode overview

| Mode | Enter | For |
| --- | --- | --- |
| **Normal** | <Keys keys="Esc" /> | Move, delete, yank, operators |
| **Insert** | <Keys keys="i" /> <Keys keys="a" /> <Keys keys="o" /> … | Type text |
| **Visual** | <Keys keys="v" /> <Keys keys="V" /> <Keys keys="Ctrl-v" /> | Select, then operate |
| **Replace** | <Keys keys="R" /> | Overwrite as you type |
| **Command-line** | <Keys keys=":" /> | Ex commands |

## Leaving modes

- <Keys keys="Esc" /> or <Keys keys="Ctrl-[" /> → Normal
- In Command-line: <Keys keys="Esc" /> cancels; <Keys keys="Enter" /> runs
- In Insert: <Keys keys="Ctrl-o" /> runs one Normal command, then returns to Insert
