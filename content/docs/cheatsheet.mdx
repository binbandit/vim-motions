Quick scan while you code. Full inventory: [All motions](/docs/motions/all). Search with <Kbd>⌘</Kbd><Kbd>K</Kbd>.

## Left-right / up-down

| Keys | Action |
| --- | --- |
| <Keys keys="h j k l" /> | Left / down / up / right |
| <Keys keys="gj gk" /> | Screen-line down / up |
| <Keys keys="- + _" /> | Up/down to first non-blank |
| <Keys keys="0 ^ $ g_" /> | Col1 / first non-blank / EOL / last non-blank |
| <Keys keys="\|" /> | Column `[count]` |
| <Keys keys="g0 g^ g$ gm gM" /> | Soft-wrap line helpers |

## Words / sentences / paragraphs / sections

| Keys | Action |
| --- | --- |
| <Keys keys="w W e E b B ge gE" /> | word / WORD moves |
| <Keys keys="( )" /> | Sentence back / forward |
| <Keys keys="{ }" /> | Paragraph back / forward |
| <Keys keys="[[ ]] [] ][" /> | Sections / col-1 braces |

## Lines / file

| Keys | Action |
| --- | --- |
| <Keys keys="gg G" /> | First / last line (`[count]` → line) |
| <Keys keys="{n}%" /> | `{n}` percent of file |
| <Keys keys="go" /> | Byte offset `[count]` |
| <Keys keys="H M L" /> | Window top / mid / bottom |

## Search / find

| Keys | Action |
| --- | --- |
| <Keys keys="*" link /> / <Keys keys="#" link /> | Word under cursor (star / hash) |
| <Keys keys="g*" link /> / <Keys keys="g#" link /> | Same without word boundaries |
| <Keys keys="/ ? n N" /> | Search; next / prev |
| <Keys keys="f F t T ; ," /> | Find / till on line; repeat |
| <Keys keys="gd gD" /> | Local / global declaration |
| <Keys keys="gn gN" /> | Next / prev match as text object |

## Text objects

| Keys | Object |
| --- | --- |
| <Keys keys="iw aw iW aW" /> | word / WORD |
| <Keys keys="is as ip ap" /> | sentence / paragraph |
| <Keys keys="ib ab iB aB" /> | `()` / `{}` |
| <Keys keys="i[ a[ i< a<" /> | `[]` / `<>` |
| <Keys keys={'i" a" i\' a\' i` a`'} /> | quotes |
| <Keys keys="it at" /> | tags |

## Matching / structure

| Keys | Action |
| --- | --- |
| <Keys keys="%" /> | Match `([{`, comment, `#if` |
| <Keys keys="[( [{" /> | Prev unmatched `(` / `{` |
| <Keys keys="]) ]}" /> | Next unmatched `)` / `}` |
| <Keys keys="]m [m ]M [M" /> | Method start/end |
| <Keys keys="[# ]#" /> | `#if` / `#endif` |
| <Keys keys="[/ ]/" /> | `/*` / `*/` |

## Marks / jumps / folds

| Keys | Action |
| --- | --- |
| <Keys keys="m{a} '{a} `{a}" /> | Set / line jump / exact |
| <Keys keys="'' ``" /> | Before latest jump |
| <Keys keys="'[ '] '< '>" /> | Change/yank/visual ends |
| <Keys keys="Ctrl-o Ctrl-i" /> | Jump list |
| <Keys keys="g; g," /> | Change list |
| <Keys keys="[z ]z zj zk" /> | Fold motions |

## Operators (not motions)

| Keys | Action |
| --- | --- |
| <Keys keys="d c y" /> | Delete / change / yank |
| <Keys keys="dd cc yy" /> | Whole line |
| <Keys keys="> < =" /> | Indent / outdent / format |
| <Keys keys="g~ gu gU" /> | Case |
| <Keys keys="p P ." /> | Put / put / repeat |

## Insert / visual / windows (quick)

| Keys | Action |
| --- | --- |
| <Keys keys="i a I A o O" /> | Enter Insert |
| <Keys keys="v V Ctrl-v gv" /> | Visual modes / reselect |
| <Keys keys="Ctrl-w h/j/k/l" /> | Focus window |
| <Keys keys=":bn :bp Ctrl-^" /> | Buffers |
| <Keys keys="gt gT" /> | Tabs |
