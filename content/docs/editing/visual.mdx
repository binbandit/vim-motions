Visual mode lets you **see** the range before you act. Prefer operators when you
already know the motion; use Visual when discovering or for block edits.

</MotionList>

## Block editing

The classic column-insert workflow:

1. <Keys keys="Ctrl-v" /> select a column across lines.
2. <Keys keys="I" /> insert at the start of each line (or <Keys keys="A" /> at the end).
3. Type text, <Keys keys="Esc" /> — applies to all lines in the block.
4. <Keys keys="x" /> / <Keys keys="d" /> delete a column; <Keys keys="r" /> replace column chars.

<Buffer
  keys="Ctrl-v j I"
  before={"|one\ntwo\nthree"}
  after={"X|one\nXtwo\nthree"}
  note="Block-select two lines, I, type X, Esc — prefixes each selected line."
/>

## Select all

`ggVG` — top, line-visual, end. Or `:%` for Ex ranges.
