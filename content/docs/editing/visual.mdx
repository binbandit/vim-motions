## Block editing

1. <Keys keys="Ctrl-v" /> select a column.
2. <Keys keys="I" /> insert at start of each line (or <Keys keys="A" /> at end).
3. Type text, <Keys keys="Esc" /> — applies to all lines.
4. <Keys keys="x" /> / <Keys keys="d" /> delete a column; <Keys keys="r" /> replace column chars.

## Select all

`ggVG` — top, line-visual, end. Or `:%` for Ex ranges.
