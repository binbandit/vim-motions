## Special marks

| Mark | Meaning |
| --- | --- |
| <Keys keys="''" /> / <Keys keys="``" /> | Previous jump position |
| <Keys keys="'." /> / <Keys keys="`." /> | Last change |
| <Keys keys="'^" /> | Last Insert exit |
| <Keys keys="'[" /> / <Keys keys="']" /> | Start/end of last yank or change |
| <Keys keys="'<" /> / <Keys keys="'>" /> | Start/end of last visual selection |
| <Keys keys="0" />–<Keys keys="9" /> | Viminfo: `0` last exit file, etc. |

## Workflow

- `mm` before a risky experiment; `''` to return.
- `mA` on an API definition; jump back from anywhere with `'A`.
- Combine with operators carefully — marks are mainly for jumping.

Full motion-oriented mark list (including `'(`, `'.`, `g'`, …): [Marks as motions](/docs/motions/marks-as-motions).
