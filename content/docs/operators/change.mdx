---
title: Change
description: "c, s, C, S — delete a range and enter Insert mode."
---

**Change** = delete + Insert. Prefer change over delete+`i` when replacing text.
After the operator, you type the replacement and hit <Keys keys="Esc" />.

Buffer demos show the buffer **after Esc** (replacement already typed).

## Motions with c

<Motion keys="cw" name="Change word" before={"const |userName = 1"} after={"const |id = 1"} note="Leaves the trailing space; type the new word then Esc." />

<Motion keys="ciw" name="Change inner word" before={"const |userName = 1"} after={"const |id = 1"} note="Whole word under cursor, wherever you are in it." />

## After change

You're in Insert mode. Edit, then <Keys keys="Esc" />. <Keys keys="." /> repeats the
same change (including typed text) elsewhere.

```
|foo bar baz
```

After `ciw` + `qux` + Esc on `foo`, then `w.`:

```
qux |qux baz
```
