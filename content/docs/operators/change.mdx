---
title: Change
description: "c, s, C, S — delete a range and enter Insert mode."
---

**Change** = delete + Insert. Prefer change over delete+`i` when replacing text.
After the operator, you type the replacement and hit <Keys keys="Esc" />.

Buffer demos show the buffer **after Esc**. Cursor lands on the **last character
you typed** (Vim’s normal Insert-exit behavior).

<Motion keys="C" name="Change to end of line" sameAs="c$" before={"const |name = value"} after={"const don|e"} note="Deleted from cursor to EOL, typed done, Esc." />

<Motion keys="cc / S" name="Change whole line" before={"keep\n|old line\nkeep"} after={"keep\nnew lin|e\nkeep"} />

## Motions with c

<Motion keys="cw" name="Change word" before={"|word here"} after={"|X here"} note="Special case: in a word, cw acts like ce — it does **not** eat the trailing space (unlike dw)." />

<Motion keys="ciw" name="Change inner word" before={"const |userName = 1"} after={"const i|d = 1"} note="Whole word under cursor, wherever you are in it." />

<Motion keys="ct;" name="Change till ;" before={"x = |foo + bar;"} after={"x = 4|2;"} note="Deletes up to (not including) `;`." />

## cw vs dw vs ciw

| Keys | On `\|word here` |
| --- | --- |
| <Keys keys="dw" /> | `\|here` — deletes word **and** following space |
| <Keys keys="cw" /> | `\|X here` — changes word, **keeps** the space |
| <Keys keys="ciw" /> | Same idea as cw when you’re inside the word, but works from any column in it |

<Buffer
  keys="c$"
  before={"keep |change the rest"}
  after={"keep O|K"}
/>

## After change

You're in Insert mode. Edit, then <Keys keys="Esc" />. <Keys keys="." /> repeats the
same change (including typed text) elsewhere.

```
|foo bar baz
```

After `ciw` + `qux` + Esc on `foo`, then `w.`:

```
qux qu|x baz
```
