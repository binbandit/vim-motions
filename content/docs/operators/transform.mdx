## Indent

<Motion keys=">>" name="Indent line" before={"|foo()"} after={"\t|foo()"} note="Adds one 'shiftwidth' of indent (shown as a tab here)." />

<Motion keys="<<" name="Outdent line" before={"\t|foo()"} after={"|foo()"} />

<Motion keys=">i{" name="Indent inside braces" before={"fn() {\n|  a()\n  b()\n}"} after={"fn() {\n|\t  a()\n\t  b()\n}"} note="Indents every line inside the {} block." />

<Motion keys="==" name="Auto-indent line" before={"fn() {\n|bad indent\n}"} after={"fn() {\n|  bad indent\n}"} note="Uses 'indentexpr' / cindent — exact spaces depend on filetype." />

<MotionList>
  <Motion keys=">{motion}" name="Indent right over motion" />
  <Motion keys="<{motion}" name="Indent left over motion" />
  <Motion keys="={motion}" name="Auto-indent / format range" />
  <Motion keys="=ap" name="Re-indent a paragraph" />
  <Motion keys="gg=G" name="Re-indent whole file" example="Careful in huge files / mixed styles" />
</MotionList>

In Visual mode: <Keys keys=">" />, <Keys keys="<" />, <Keys keys="=" />. Use `.` to repeat indent.

## Case

<Motion keys="~" name="Toggle case of character" before={"|Hello"} after={"h|ello"} />

<Motion keys="gUl" name="Uppercase character" before={"|hello"} after={"|Hello"} />

<Motion keys="guiw" name="Lowercase word" before={"const |UserName = 1"} after={"const |username = 1"} />

<Motion keys="gUiw" name="Uppercase word" before={"const |userName = 1"} after={"const |USERNAME = 1"} />

<Motion keys='gUi"' name="Uppercase inside quotes" before={'msg = "|hello|"'} after={'msg = "|HELLO|"'} />

<MotionList>
  <Motion keys="g~{motion}" name="Toggle case over motion" />
  <Motion keys="g~~" name="Toggle case on line" />
</MotionList>

## Substitute (command)

Not an operator, but related:

```vim
:s/old/new/        " current line
:s/old/new/g       " all on line
:%s/old/new/g      " whole file
:%s/old/new/gc     " confirm each
```
