## Indent

<MotionList>
  <Motion keys=">{motion}" name="Indent right" />
  <Motion keys="<{motion}" name="Indent left" />
  <Motion keys=">>" name="Indent line" />
  <Motion keys="<<" name="Outdent line" />
  <Motion keys="={motion}" name="Auto-indent / format range" />
  <Motion keys="==" name="Auto-indent line" />
  <Motion keys=">i{" name="Indent inside braces" />
  <Motion keys="=ap" name="Re-indent a paragraph" />
  <Motion keys="gg=G" name="Re-indent whole file" example="Careful in huge files / mixed styles" />
</MotionList>

In Visual mode: <Keys keys=">" />, <Keys keys="<" />, <Keys keys="=" />. Use `.` to repeat indent.

## Case

<MotionList>

## Substitute (command)

Not an operator, but related:

```vim
:s/old/new/        " current line
:s/old/new/g       " all on line
:%s/old/new/g      " whole file
:%s/old/new/gc     " confirm each
```
