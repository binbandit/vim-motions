---
title: Delete
description: Cut text with motions — d, dd, D, x, X.
---

Delete removes text into a register (default: unnamed `"`). Pair `d` with any
motion; the deleted region is the same range an operator would cover for
change/yank.

## Character delete

<Motion keys="x" name="Delete character" sameAs="dl" before={"co|nst x = 1"} after={"co|st x = 1"} note="Deletes the character under the cursor." />

<Motion keys="X" name="Delete before cursor" sameAs="dh" before={"cons|t x = 1"} after={"con|t x = 1"} note="Deletes the character left of the cursor." />

## Line delete

<Motion keys="dd" name="Delete line" before={"a()\n|b()\nc()"} after={"a()\n|c()"} note="Removes the whole current line; cursor lands on the next line." />

<Motion keys="D" name="Delete to end of line" sameAs="d$" before={"const |name = value"} after={"const |"} note="Keeps everything left of the cursor." />

## Motions with d

<Motion keys="dw" name="Delete word" before={"const |userName = 1"} after={"const | = 1"} note="Deletes from cursor through the end of the word (space often remains)." />

<Motion keys="diw" name="Delete inner word" before={"const |userName = 1"} after={"const | = 1"} note="Deletes the whole word under the cursor, regardless of where you are in it." />

<Motion keys="daw" name="Delete a word" before={"const |userName = 1"} after={"const |= 1"} note="Like diw but also eats the trailing space (or leading space if at EOL)." />

<Motion keys="d$" name="Delete to end of line" before={"let |x = 1; // keep"} after={"let |"} />

<Motion keys="d0" name="Delete to start of line" before={"    let |x = 1"} after={"|x = 1"} />

<Motion keys="d^" name="Delete to first non-blank" before={"    |let x = 1"} after={"    |x = 1"} note="Leaves leading indent if the cursor started after it." />

<Motion keys="dgg" name="Delete to first line" before={"a\nb\n|c\nd"} after={"|d"} note="Deletes from the current line up through line 1." />

<Motion keys="dG" name="Delete to last line" before={"a\n|b\nc\nd"} after={"|a"} note="Deletes from the current line through EOF." />

<Motion keys="d%" name="Delete to matching pair" before={"foo(|bar, baz)"} after={"foo|"} note="Deletes through the matching `)`." />

## Counts

`3dd` deletes three lines. `2dw` deletes two words. Counts multiply the motion
(or the linewise repeat for `dd`).

```
|one two three four
```

After `2dw`:

```
|three four
```

## Visual delete

In Visual mode, `d` or `x` deletes the selection. Linewise Visual + `d` is like
`dd` for the highlighted lines.

## Registers

`"adw` deletes a word into register `a`. `"_dw` deletes into the black hole
register (nothing yanked — useful when you don’t want to overwrite `"`).
