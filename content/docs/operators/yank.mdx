Yank copies into a register without deleting. Put pastes. Characterwise vs
linewise paste depends on **what** you yanked.

## Yank

<Motion keys="yiw" name="Yank inner word" before={"const |userName = 1"} after={"const |userName = 1"} note="Buffer unchanged — word is now in the unnamed register." />

<Motion keys="yy / Y" name="Yank line" before={"a()\n|b()\nc()"} after={"a()\n|b()\nc()"} note="Linewise yank — p will paste as a new line below. Default Vim maps Y to yy (Vi traditionally used y$)." />

<Motion keys="y$" name="Yank to end of line" before={"const |name = value"} after={"const |name = value"} note="Characterwise — p pastes after the cursor on the same line." />

<Motion keys='yi"' name="Yank inside quotes" before={'msg = "|hello|"'} after={'msg = "|hello|"'} />

<Motion keys="yap" name="Yank a paragraph" before={"keep\n\n|para one\nstill\n\nkeep"} after={"keep\n\n|para one\nstill\n\nkeep"} />

## Put (paste)

Assume the unnamed register holds `userName` (from `yiw` above). After put, the
cursor sits on the **last character** of the pasted text.

<Motion keys="p" name="Put after cursor" before={"const |x = 1"} after={"const xuserNam|e = 1"} note="Characterwise put inserts after the cursor." />

<Motion keys="P" name="Put before cursor" before={"const |x = 1"} after={"const userNam|ex = 1"} note="Inserts before the cursor." />

Linewise put — after `yy` on `b()`:

## Registers (quick)

| Register | Use |
| --- | --- |
| <Keys keys='"' /> | Unnamed — last delete/yank |
| <Keys keys='"a' />–<Keys keys='"z' /> | Named |
| <Keys keys='"A' /> | Append to register `a` |
| <Keys keys='"0' /> | Last **yank** (not deletes) |
| <Keys keys='"1' />–<Keys keys='"9' /> | Delete history |
| <Keys keys='"+' /> | System clipboard (when available) |
| <Keys keys='"*' /> | Primary selection (Linux) |
| <Keys keys='"_' /> | Black hole — discard |

```text
"ayy      yank line into a
"ap       put from a
"+yiw     yank word to clipboard
"_dd      delete line, keep previous yank
```
