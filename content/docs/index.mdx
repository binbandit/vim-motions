**Vim Motions** is a single reference for how you move and act in Vim. Search any key, skim a category, or open the cheatsheet beside your editor.

## How to use this site

1. Press <Kbd>⌘</Kbd><Kbd>K</Kbd> / <Kbd>Ctrl</Kbd><Kbd>K</Kbd> and type a key or idea (`word`, `delete inside`, `f`, `ci"`).
2. Follow [Getting started](/docs/getting-started) if you’re learning; use the sidebar families when you already know the name.
3. Keep the [cheatsheet](/docs/cheatsheet) pinned for dense lookup.

## The mental model

Vim editing is **operator + motion** (or **operator + text object**):

```text
d    w     → delete a word
c    i"    → change inside quotes
y    ap    → yank a paragraph
>    }     → indent to next paragraph
```

## Tip

Counts multiply almost everything: <Keys keys="3w" /> moves three words, <Keys keys="2dw" /> deletes two words, <Keys keys="5j" /> jumps five lines.
